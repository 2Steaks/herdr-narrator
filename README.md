# Herdr Narrator

Speaks one sentence aloud when an AI coding agent in a Herdr pane finishes, gets blocked, or needs a decision.

```sh
sh narrator/install.sh
```

Everything else, including setup, settings, voices and troubleshooting, is in [`narrator/README.md`](narrator/README.md).

- `narrator/`: the program, its Herdr plugin and app overlay, and its tests.
- `docs/adr/`: why it is built the way it is.
- `GLOSSARY.md`: the words the code and docs use.
